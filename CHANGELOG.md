# История изменений

Формат версий: Semantic Versioning. Теги и GitHub Releases указывают на точный коммит выпуска. Для дальнейших выпусков добавляйте сюда дату, функции, исправления, ограничения, результаты тестов и изменения зависимостей, БД и конфигурации.

## v0.3.1 — 2026-10-31

- Восстановление временного HTTPS-туннеля через localhost.run: адрес проверяется, после обрыва создаётся новый и обновляется кнопка Mini App в Telegram.
- `/app` берёт текущий адрес из локального файла, поэтому бот не нужно перезапускать при смене временной ссылки.
- Зависимости и схема БД не изменились. Стабильный адрес по-прежнему требует постоянного хостинга.
- Проверено: 147 тестов, Ruff, lock-файл и зависимости; принудительный обрыв SSH-туннеля привёл к новому рабочему HTTPS-адресу и обновлению кнопки Telegram.

## v0.3.0 — 2026-10-31

### Добавлено

- Адаптивный Telegram Mini App: обзор, мониторинги, каталог, поиск, сортировка, карточки объявлений и избранное.
- Управление теми же мониторингами через веб: создание, фильтры, пауза, возобновление и ручная проверка. Команды чата сохранены.
- FastAPI с проверкой подписи Telegram `initData`, срока входа и списка разрешённых пользователей; персональный вход через `/app`, если Telegram не передал данные запуска.
- Поддержка товаров любых категорий в поиске по модели и памяти, а также ссылок с регионом `all` (вся Россия). Мониторинг сохраняется без ожидания ответа Авито; проверка фильтров идёт в фоне и повторяется после временной блокировки.
- Запуск веб-сервера вместе с ботом при наличии публичного `WEBAPP_URL`, кнопка Mini App в меню Telegram.

### Совместимость и проверка

- Добавлены FastAPI и Uvicorn; схема SQLite не менялась. Новые необязательные переменные: `WEBAPP_URL`, `WEBAPP_HOST`, `WEBAPP_PORT`.
- Локально: 146 тестов, Ruff, синтаксис JavaScript, lock-файл и зависимости прошли. Публичная временная страница доступна, API без Telegram-входа закрыт. Mini App открылся на устройстве пользователя; вход через `/app` и длительная работа временного туннеля пока не подтверждены. Живой Авито при проверке ответил `403` с этого компьютера.

## v0.2.0 — 2026-10-31

### Добавлено

- Поиск по названию внутри мониторинга, сортировка по времени и цене, страничный просмотр и подборка выгодных объявлений с переходом в карточку.
- Ручная постановка активного мониторинга в очередь проверки.
- Проверка просмотров на странице нового объявления перед уведомлением: вероятные повторные публикации отменяются, неподтверждённые помечаются; снижение цены продолжает работать отдельно.

### Совместимость и проверка

- Схема SQLite обновляется до версии 9 без удаления данных: добавлены результат проверки новизны, общее и сегодняшнее число просмотров.
- Пустые необязательные поля `.env` игнорируются. Зависимости не менялись.
- Локально прошли 139 тестов, Ruff, проверка lock-файла и зависимостей; Telegram API `getMe` ответил с перевыпущенным пользовательским токеном. Живой Авито, доставка сообщений и Docker не проверены.

## v0.1.0 — 2026-10-22

Первая публикация Telegram-приложения в Fork исходного `avito-parser`. Исходный CLI сохранён. Исходный коммит выпуска: [`v0.1.0`](../../tree/v0.1.0); точный SHA также указан в GitHub Release.

### Добавлено

- Русскоязычные команды и кнопки Telegram, создание нескольких мониторингов, изменение фильтров, пауза и возобновление.
- Сбор через существующий парсер, сохранение прогресса, SQLite, рыночная аналитика, оценки риска, история цен и очередь уведомлений.
- Необязательный анализ текста и фотографий, локальные хеши, избранное, Excel, тихие часы и сводка.
- Docker-конфигурация, документация и автоматические тесты. GitHub Actions проверяет Python 3.11/3.12 на Linux и 3.12 на Windows.

### Исправлено перед выпуском

- Пауза, поставленная во время запроса к источнику, не снимается результатом этого запроса.
- Повторный анализ фотографии не снижает оценку объявления снова.
- В «Лучшие предложения» не попадают объявления с высоким риском или ценой выше рынка.
- Для Windows добавлен пакет часовых поясов `tzdata`, чтобы настройки `Europe/Moscow` работали без системной базы зон.

### Совместимость и обновление

- Новые зависимости: aiogram, SQLAlchemy, pydantic-settings, Pillow, imagehash, httpx и `tzdata` для Windows; они закреплены в `uv.lock`.
- Новая SQLite-схема хранится отдельно от прежних файлов CLI в `data/intelligence.sqlite3`. Изменения схемы применяются при запуске без удаления пользовательских данных.
- Новые переменные перечислены в `.env.example`; обязательны только `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ALLOWED_USER_IDS`.
- Для обновления остановите бот, сделайте резервную копию `data/`, получите тег выпуска и выполните `uv sync --locked`. Инструкции Docker — в `README_BOT.md`.

### Проверка и ограничения

- Локально: 134 теста прошли; Ruff, форматирование, проверка `uv.lock` и совместимости зависимостей прошли.
- Живые Telegram, Авито и AI не проверены без пользовательских учётных данных. Docker-сборка в локальной среде не запускалась. Дополнительные ограничения — в `PROJECT_STATUS.md`.
