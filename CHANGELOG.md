# История изменений

Формат версий: Semantic Versioning. Теги и GitHub Releases указывают на точный коммит выпуска. Для дальнейших выпусков добавляйте сюда дату, функции, исправления, ограничения, результаты тестов и изменения зависимостей, БД и конфигурации.

## v0.1.0 — 2026-10-22

Первая публикация Telegram-приложения в Fork исходного `avito-parser`. Исходный CLI сохранён. Исходный коммит выпуска: [`v0.1.0`](../../tree/v0.1.0); точный SHA также указан в GitHub Release.

### Добавлено

- Русскоязычные команды и кнопки Telegram, создание нескольких мониторингов, изменение фильтров, пауза и возобновление.
- Сбор через существующий парсер, сохранение прогресса, SQLite, рыночная аналитика, оценки риска, история цен и очередь уведомлений.
- Необязательный анализ текста и фотографий, локальные хеши, избранное, Excel, тихие часы и сводка.
- Docker-конфигурация, документация и автоматические тесты. GitHub Actions проверяет Python 3.11/3.12 на Linux и 3.12 на Windows.

### Исправлено перед выпуском

- Пауза, поставленная во время запроса к источнику, не снимается результатом этого запроса.
- Повторный анализ фотографии не снижает оценку объявления снова.
- В «Лучшие предложения» не попадают объявления с высоким риском или ценой выше рынка.
- Для Windows добавлен пакет часовых поясов `tzdata`, чтобы настройки `Europe/Moscow` работали без системной базы зон.

### Совместимость и обновление

- Новые зависимости: aiogram, SQLAlchemy, pydantic-settings, Pillow, imagehash, httpx и `tzdata` для Windows; они закреплены в `uv.lock`.
- Новая SQLite-схема хранится отдельно от прежних файлов CLI в `data/intelligence.sqlite3`. Изменения схемы применяются при запуске без удаления пользовательских данных.
- Новые переменные перечислены в `.env.example`; обязательны только `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ALLOWED_USER_IDS`.
- Для обновления остановите бот, сделайте резервную копию `data/`, получите тег выпуска и выполните `uv sync --locked`. Инструкции Docker — в `README_BOT.md`.

### Проверка и ограничения

- Локально: 134 теста прошли; Ruff, форматирование, проверка `uv.lock` и совместимости зависимостей прошли.
- Живые Telegram, Авито и AI не проверены без пользовательских учётных данных. Docker-сборка в локальной среде не запускалась. Дополнительные ограничения — в `PROJECT_STATUS.md`.
