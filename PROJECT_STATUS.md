# Состояние проекта

**Проект:** Avito Intelligence Bot — личный Telegram-бот для мониторинга объявлений Авито поверх исходного `avito-parser`.

**Версия:** 0.3.0. **Обновлено:** 2026-10-31. История выпусков — в [CHANGELOG.md](CHANGELOG.md).

## Компоненты

- `avito.py`, `avito_client.py`, `link_resolver.py`, `apartments.py` — исходный CLI и повторно используемые интерфейсы парсера.
- `intelligence/bot.py` — команды, кнопки, FSM, планировщик, Telegram-уведомления.
- `intelligence/web.py`, `intelligence/static/` — защищённый API и адаптивный интерфейс Telegram Mini App.
- `intelligence/service.py` — поиски, постраничный сбор, состояние объявлений, очередь и правила повторной оценки.
- `intelligence/db.py` — модели SQLite, создание схемы и последовательные дополнения существующей схемы через `ALTER TABLE`.
- `intelligence/analysis.py` — сопоставление модели и памяти, дефекты, продавцы, медианный рынок, риск и баллы.
- `intelligence/text_ai.py`, `intelligence/vision.py` — необязательный OpenAI-совместимый анализ текста и фотографий, локальные хеши изображений.
- `intelligence/export.py`, `intelligence/legacy.py`, `intelligence/config.py` — Excel, импорт старых поисков, конфигурация.
- `tests_bot/` — локальные тесты нового приложения; исходные тесты сохранены.

Схема взаимодействия подробно описана в [ARCHITECTURE.md](ARCHITECTURE.md). Запуск и обновление — в [README_BOT.md](README_BOT.md).

## Работает и проверено локально

- Telegram-обработчики команд, создания мониторинга, фильтров, паузы, возобновления, ручной проверки, поиска объявлений, удаления, базы, избранного и Excel проверены тестами с имитацией Telegram. Mini App и чат используют один `Service` и одну БД.
- Несколько поисков, постраничный первичный сбор, восстановление состояния, история цен, события снижения цены, дедупликация уведомлений и проверка вероятных повторных публикаций по просмотрам проверены локальными сценариями.
- Аналитика группирует iPhone по модели и памяти, отсекает явные дефекты и статистические выбросы, показывает недостаточную выборку.
- Детерминированная оценка работает без AI. Для фотографий проверены хеширование и обработка сбоев; ответы AI валидируются по схеме.
- SQLite сохраняет данные между запусками; старые данные CLI импортируются без удаления исходных файлов.
- Оригинальный CLI `avito.py` остаётся в проекте; его тесты входят в общий прогон.

Последняя локальная проверка перед публикацией: **146 passed**, Ruff, `uv lock --check`, `uv pip check` и синтаксис JavaScript без ошибок. API Mini App проверен на подпись, срок входа, одноразовый билет и разграничение доступа. Временный HTTPS-адрес ответил `200` для страницы и `401` для API без входа; Telegram подтвердил кнопку Mini App в меню. Пользователь открыл Mini App, но Telegram не передал `initData`; для этого добавлен вход через `/app`. Живой Авито при проверке ответил `403` с этого компьютера. GitHub Actions выполняет тесты на Python 3.11 и 3.12 под Linux, на Python 3.12 под Windows. Итог CI следует проверять по конкретному коммиту.

## Не проверено на внешних сервисах

- Вход через новую персональную кнопку `/app` на устройстве пользователя и доставка уведомлений.
- Долгое наблюдение через живой Авито и доступность конкретной выдачи при ограничениях источника.
- Реальные запросы к выбранному пользователем Vision/LLM API.
- Сборка и длительная эксплуатация Docker-контейнера в текущей среде.
- Постоянная доступность временного HTTPS-туннеля: адрес меняется при перезапуске, гарантии времени работы нет.

## Известные ограничения и технический долг

- Авито может менять структуру ответа, ограничивать запросы, показывать CAPTCHA или блокировать IP. Бот переводит мониторинг в `source_unavailable` и повторяет попытку с задержкой; обход блокировки не гарантирован.
- При появлении той же вещи с новым ID бот оценивает новизну по просмотрам, но не объединяет публикации. Эвристика может ошибаться при неполных данных или около полуночи. Похожесть фото отмечается только среди уже обработанных кандидатов.
- Наблюдение охватывает первые `WATCH_PAGES` страниц. «Не видно в выдаче» не доказывает продажу.
- Рыночная оценка основана на ценах объявлений, а не на подтверждённых сделках. Для других категорий, кроме iPhone, группировка по заголовку остаётся консервативной и требует проверки на реальных данных.
- При аварии между отправкой сообщения и записью её результата в SQLite возможно повторное уведомление.
- Обновление схемы через `ALTER TABLE` подходит для текущей девятой версии, но требует формальных версионированных миграций при дальнейшем росте схемы.
- Корневой код исходного репозитория не содержит явной лицензии. Fork сохраняет связь с автором; новая лицензия на исходный код не назначалась.
